## 🔧 Also building

**[TUF K3 RGB Driver](https://github.com/JoaquinSasso/TUF-K3-Gen-II-Reactive-RGB)**
Lightweight Python driver for a mechanical keyboard, built from scratch by
reverse-engineering its USB/HID protocol — no official documentation available.
Covers USB traffic capture, packet structure analysis, and a deliberate
security tradeoff: moved from a global keyboard hook to fully passive HID
reads to stay clear of kernel-level anti-cheat heuristics.

Outside my usual mobile/web work, but the closest thing I have to systems-level
programming — protocol analysis, byte-level communication, reverse engineering
without a spec.
